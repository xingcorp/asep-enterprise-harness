# Experimental Tools: RTK and Caveman

## RTK

Only an optional `OutputReducer` after trusted raw capture. Initially allow listing/inventory outputs; deny failures, diagnostics, security, migration, benchmarks, JSON and production operations. Promotion is per command + repository + model + task type and measured by accepted-task cost and diagnostic completeness.

## Caveman

Not a code/config/document compressor in ASEP. At most, use its brevity concept for non-canonical human status messages under a native structured response policy. Never modify ProductSpec, ADR, WorkOrder, review, evidence, memory, Dockerfile, Makefile or scripts.

## Circuit breaker

Any mismatch between raw and reduced semantics, increased false success, increased extra tool calls or data-loss signal disables the reducer and preserves the raw artifact for investigation.
