# Technology Radar — 2026-07-14

## Adopt/Core

- Temporal: durable orchestration.
- PostgreSQL: operational state and projections.
- Git/worktree: canonical code and isolation.
- Object storage: immutable evidence.
- OpenTelemetry: correlation and telemetry.
- Internal ProductSpec, WorkOrder, policy and skill registry.

## Trial / first-class adapters

- Claude Code and Codex: primary coding/review providers.
- OpenHands: provider/agent server/ACP host after compatibility tests.
- Spec Kit importer: normalize specs into canonical schemas.
- Open Design: design capability with pinned artifact revisions.

## Assess / optional adapters

- Google ADK: bounded inner graph; pin/test releases.
- DeerFlow 2: research/general-agent provider, not durable core.
- Mem0: episodic memory only after tenant/provenance eval.
- Graphiti: temporal knowledge graph for brownfield.
- Microsoft Agent Framework/LangGraph: alternatives for inner workflows; do not run multiple owners of state.
- Spec Kitty: work-package/orchestrator contract reference and trial adapter.
- BMAD/Open GSD Core: methodology importers.

## Hold / experimental

- RTK: listing-output reduction only after raw capture and A/B evidence; never diagnostics/security/migration path.
- Caveman: human-facing concise status only; never canonical documents or code/config compression.
- Public skill catalogs: discovery/quarantine only.

## Framework-soup rule

A production execution path must name exactly one durable orchestrator, one canonical state model, one primary agent-session runtime per provider and one assurance authority. Optional capabilities cannot silently become state owners.
