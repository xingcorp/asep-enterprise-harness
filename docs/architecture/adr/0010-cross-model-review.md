# ADR 0010 — Require cross-model review for selected R2–R4 changes

- **Status:** Accepted
- **Date:** 2026-07-14

## Context

ASEP must operate for long periods, across model/provider changes, crashes and high-risk software changes. The decision must remain auditable and reversible.

## Decision

Fresh context is mandatory; different family/provider is policy-dependent; deterministic evidence remains stronger than model review.

## Consequences

Reduces correlated assumptions but adds cost and must be measured.

## Revisit when

Measured production evidence invalidates the assumptions, or a replacement passes compatibility, recovery, security and cost/quality evaluation.
