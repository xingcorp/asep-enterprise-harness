# Team and Ownership

Initial core team:

- Platform architect/product owner.
- Workflow/control-plane engineers.
- Sandbox/security engineer.
- Assurance/evaluation engineer.
- Developer-experience/code-intelligence engineer.
- SRE/observability owner.
- Pilot repository owners.

Every adapter, skill, policy and evaluation dataset has a named owner and compatibility window. High-risk waivers name a risk-acceptance owner and expiry. Repository owners—not the platform—own product semantics and final R3/R4 approvals.
